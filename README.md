# CampusHub 文档导航

## 项目简介

CampusHub 是一个以知识共享为核心的论坛生态系统，积分体系命名为 CHB（CampusHub Coin）。论坛通过 OAuth2 应用接入机制，实现跨应用积分流通。参考 linux.do 的社区运营模式，构建包含论坛、积分体系、积分集市、OAuth2 应用接入的完整生态。
