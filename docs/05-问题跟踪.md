## P1 系统配置保存不生效

**状态**：已验证

**问题描述**：管理后台设置页点"保存配置"看似成功，实际后端 UpdateSettings 只有 TODO 注释，什么都没存。GetSettings 也返回硬编码值，不读数据库。

**涉及文件**：
- `chb-backend/internal/handler/admin_handler.go` — UpdateSettings 方法，缺持久化逻辑
- `chb-backend/internal/service/admin_service.go` — GetSettings 硬编码返回，UpdateSettings 未实现

**修复方案**：实现 system_configs 表的读写，GetSettings 从数据库读取，UpdateSettings 写入数据库。

## P6 AdminAuth 不校验 key 值

**状态**：已验证

**问题描述**：中间件只检查 X-Admin-Key 头是否存在，不验证具体值。任何非空字符串都能通过。

**涉及文件**：
- `chb-backend/internal/middleware/auth.go` — AdminAuth 函数
- `chb-backend/config.yaml` 或环境变量 — 需配置合法 admin key

**修复方案**：AdminAuth 校验 key 值与配置中的 admin_key 是否一致。

---

## P7 前端硬编码 admin key

**状态**：已验证

**问题描述**：api.ts 中硬编码 campushub-admin-2026，暴露在浏览器端。

**涉及文件**：
- `chb-frontend/src/lib/api.ts` — X-Admin-Key 硬编码

**修复方案**：改为通过 Next.js API route 或服务端代理转发 admin 请求，不在浏览器端暴露 key。临时方案：使用环境变量 NEXT_PUBLIC_ADMIN_KEY（仍暴露但可区分环境）。
